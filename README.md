# Редактор ленты

Атмосферная интерактивная игра о степенях сравнения прилагательных и наречий. Игрок проверяет посты, сторис, комментарии и отзывы перед публикацией.

**[Открыть игру](https://kypalagina-afk.github.io/redaktor-lenty/)**

## Возможности

- 20 публикаций: правильные тексты чередуются с текстами с ошибками.
- Редактирование прямо в тексте: удаление лишних слов, замена формы, сборка фразы и поиск ошибки.
- Короткие объяснения, подсказки, статистика и повтор заданий с ошибками.
- Автоматическое сохранение прогресса на устройстве.
- Адаптация для компьютера, планшета и телефона, отключаемые звуки.
- Все стили, скрипты и изображения встроены в один HTML-файл.

## Локальный запуск

Скачайте `index.html` и откройте его в браузере. Установка зависимостей, сервер и интернет не нужны.

## Размещение

GitHub Pages публикует `index.html` из корня ветки `main`. Обновления этой ветки автоматически появляются на сайте.

Изображения созданы с помощью Imagegen.
